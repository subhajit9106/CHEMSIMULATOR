# ChemSimulator

**AI and data-science driven chemical process simulation platform**, built by **Subhajit Majumder**.

It combines physics-based unit operation models with a Data Lab that applies machine learning and data analysis to them. It runs entirely in the browser, with no backend, libraries or build step.

## Unit operation modules

| Module | Method |
| --- | --- |
| Pipe flow | Darcy–Weisbach pressure drop, 64/Re (laminar) and Swamee–Jain (turbulent) |
| Heat exchanger | LMTD method, counter-current vs parallel area |
| Reactor | Ideal CSTR and PFR sizing, first-order kinetics |
| Mixer | Steady-state total and component balance |

## Data Lab (AI / ML / data science)

| Tool | What it does |
| --- | --- |
| Kinetics fitting | Regression on experimental concentration-vs-time data: log-linear regression, Gauss–Newton nonlinear least squares, R², RMSE, residual plot, first- vs second-order model selection. Upload a CSV and send the fitted *k* to the Reactor module. |
| Neural surrogate | A multilayer perceptron (3-16-16-1, tanh, Adam optimiser) written from scratch and trained in the browser on 1,500 simulated pipe cases. Configurable sensor noise is added to the training targets and scores are measured against the clean physics on an 80/20 split. A multiple linear regression baseline (OLS) trained on the same data is shown for comparison, along with loss curves, a predicted-vs-actual plot and live predictions. A warning appears if the Pipe flow fluid properties change after training. |
| Monte Carlo | 5,000 runs with normally distributed input uncertainty. Histogram, percentiles and a correlation-based input influence ranking. |
| Optimizer | Finds the pipe diameter with minimum annual cost (capital vs pumping energy) using a scan plus golden-section refinement, and compares it with standard sizes and your current design. Supports USD and INR, and can apply the chosen standard size back to the Pipe flow module. |
| Anomaly detection | Simulates 200 plant readings with gradual fouling or a sudden valve blockage. The model predicts healthy pressure drop, residual z-scores are plotted on a control chart with ±2.5σ limits, and precision, recall and F1 are reported against the known fault labels. |

## Interface highlights

- Flowsheet with live telemetry badges, one-click process presets (cooling water, viscous crude, high-velocity solvents), and flow animation whose speed and colour follow the pipe velocity and regime.
- Live neural-network diagram that lights up the forward pass for your inputs.
- Kinetics workbench with dataset presets, an editable table synced with a raw CSV editor, and drag-and-drop file upload.

## Python companion (notebook and script)

The `python/` folder reproduces the same calculations and data-science tools offline:

| File | Purpose |
| --- | --- |
| `python/chemsimulator.py` | Script: unit operations, kinetics fitting, neural surrogate vs linear baseline, Monte Carlo, optimiser, anomaly detection. Saves plots to `python/figures/`. |
| `python/chemsimulator.ipynb` | The same code as a Jupyter / Google Colab notebook. |
| `python/requirements.txt` | `numpy`, `scipy`, `scikit-learn`, `matplotlib` |

Run locally with `pip install -r python/requirements.txt` then `python python/chemsimulator.py`. For Colab, open the notebook from GitHub (colab.research.google.com, GitHub tab) and choose Runtime, Run all.

## Run locally

Open `index.html` in a browser. Fonts load from Google Fonts when online.

## Publish with GitHub Pages

1. Create a new repository (for example `chemsimulator`) and upload these files.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Your site appears at `https://<your-username>.github.io/chemsimulator/`.

## Notes

The flow animation is an educational schematic, not CFD or a plant simulation. The neural surrogate is trained on data generated by the physics model, so it is a fast approximation valid only within its training range (flow velocity 0.1 to 6 m/s). Results are for learning and quick estimates, not final design.
